# ITH5 员工上手

公司把 Claude Code 的 skill / command / agent 统一分发到你的电脑上。**三条命令，一次搞定，之后自动更新。**

---

## 装

```sh
curl -fsSL https://<服务端地址>/install.sh | sh
ITH5_SERVER=https://<服务端地址> ith5 login
ith5 sync
```

`login` 会打开浏览器并显示一个验证码，在浏览器里用你的公司账号登录、输入那个码即可。

装完**重启一次 Claude Code**，然后敲 `/` 就能看到公司的技能了。

> 只有第一次需要重启：Claude Code 会监视技能目录，但目录是这次新建的，它还没开始盯。之后的更新都是实时生效的。

如果提示 `~/.local/bin 不在 PATH 中`，按它给的那行加进你的 shell 配置。

---

## 用

装完就没你什么事了。技能会出现在 Claude Code 的 `/` 菜单里：

- **skill 类型**：Claude 判断相关时会自动用，你也可以敲 `/名称` 主动触发
- **command 类型**：只有你敲 `/名称` 才会运行
- **agent 类型**：不在 `/` 菜单里。它落在 `~/.claude/agents/`，由别的 skill 在需要时派发给它干活，你通常不用直接管它

跑 `ith5 status` 能看到每一项装在哪。

## 日常

| 什么时候 | 做什么 |
|---|---|
| 管理员说更新了内容 | `ith5 sync` |
| 好几天没同步 | `ith5 sync` |
| 想看自己有什么 | `ith5 status` |
| 出问题 | `ith5 doctor` |

`ith5 doctor` 会逐项体检并告诉你该做什么，遇到任何异常先跑它。

---

## 常见问题

**我改了公司发的文件，然后同步说「受阻」**

这是有意的：**你的改动不会被覆盖**。同步会跳过这一项并原样保留你的版本，
公司的新版本不会下来。想拿新版就删掉那个文件再 `ith5 sync`。

反过来也成立——你自己写的 skill 和 agent，即使和公司发的重名，也不会被动。

**技能没出现在 `/` 菜单里**

先 `ith5 status` 看是否已安装。已安装的话**重启 Claude Code**——首次安装后需要重启一次。

**`ith5 sync` 说「受阻」**

```
! corp-db-review 跳过：该路径已存在同名内容，未做任何改动
```

你的 `~/.claude/skills/` 下已经有一个同名目录。**我们不会覆盖你自己的东西。**

要用公司版本，把你的那个改名或删掉再同步；想留着自己的，忽略这条警告即可（公司那份不会装上）。

**连不上服务端**

```
连不上服务端。
  · 检查网络或 VPN 是否已连接
  · 已安装的内容仍然可用，恢复网络后再跑 ith5 sync 即可
```

断网不影响已装的内容，正常用就行。

**换了新电脑**

在新电脑上重跑那三条命令即可。

**我自己写的 skill 会被删掉吗**

不会。ITH5 只管它自己装的那些入口，**从不进入你的目录内部增删文件**。你自己建的技能、笔记、附属文件都不会被碰。

## 记录了我什么

透明起见，说清楚：

### 会记录

- 你**拿到了**哪个内容的哪个版本
- 你用 Claude Code 的**哪个工具**（Edit / Write / Bash）
- 动了**哪个仓库的哪个文件**、改了几行
- 执行了什么**命令名**（只有命令名，如 `npm`）

### 不会记录

- ❌ 文件内容
- ❌ 代码 diff
- ❌ **完整命令行**（`npm run build --token xxx` 只记 `npm`）
- ❌ 环境变量
- ❌ 你本机的绝对路径（只记相对仓库根的路径）
- ❌ **你和 AI 说的话**
- ❌ 模型的回复

举个实例。你执行了：

```sh
AWS_SECRET=xyz npm run build --token hunter2
```

服务端存的是：

```json
{"repo": "github.com/acme/web", "bash_command": "npm"}
```

### 本机关闭

改 `~/.ith5/config.json`：

```json
{ "telemetry": { "enabled": false } }
```

关闭后本机不再产生任何记录。管理后台会显示"该用户已关闭上报"。

## 离职时

管理员在后台停用你的账号后，你下次 `ith5 sync` 时客户端会自动清理公司分发的内容。

也可以自己主动清：

```sh
ith5 logout --purge
```

这会移除公司分发的全部内容、本地仓库、凭据和审计 hook。**你自己的技能和配置不受影响。**

## 命令速查

```sh
ith5 login            登录并绑定本机
ith5 sync             同步公司内容
ith5 status           看当前状态与已安装内容
ith5 doctor           体检，出问题先跑它
ith5 logout           登出
ith5 logout --purge   登出并移除公司分发的内容
```
